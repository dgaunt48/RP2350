# RP2350 - Various RP2350 Based Test Projects.

## DRAM_Tester
Code Based On https://github.com/schlae/pico-dram-tester.git
Vastly Cut Down. Just Learning How The RP2350 PIO Works.

## RP2350_LogicV6
50 x 50mm 4 layer self contained version of gusmanb's Logic Analyzer Version 6 Hardware.

![Working Board](RP2350_LogicV6/Images/Board.jpg?raw=true "Working Board")

## RP2350b_40GPIO
Simple RP2350b dev board with 40 level shifted gpio pins and 3 bit VGA output.

![Working Board](RP2350b_40GPIO/Images/Board.jpg?raw=true "Working Board")

## RTC_MCP951X
Connect a MCP951X Spi Real Time Clock to the Raspberry Pi Pico.
